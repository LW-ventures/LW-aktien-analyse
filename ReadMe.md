# Aktien-Analyse

Tägliche, verschlüsselte Marktanalyse. Inhalte sind nur mit Passwort lesbar.

- `index.html`, `app.js`, `style.css`: Webseite (entschlüsselt im Browser)
- `keys.json`: öffentlicher Schlüssel und passwortgeschützte Zugänge
- `reports/`: verschlüsselte Tagesberichte
- `scripts/`: Datenabruf und Verschlüsselung (siehe `ROUTINE.md`)
- `tools/schluessel.html`: Passwörter hinzufügen oder sperren
